# Kaelo 桌面视觉自动化系统 - Verification Checklist

## 项目初始化
- [ ] 项目初始化完成，目录结构符合模块化要求（屏幕捕获、坐标计算、AI通信、指令解析、安全校验、操作执行独立模块）

## AGENT-SCREEN - 屏幕捕获
- [ ] 屏幕捕获模块能够实时截取完整、清晰的屏幕画面，分辨率与屏幕一致
- [ ] 屏幕捕获延迟≤500ms
- [ ] 屏幕捕获失败时能够自动重试，最多重试3次

## AGENT-SCREEN - 元素识别与坐标生成
- [ ] 元素识别模块能够识别按钮、输入框、图标、窗口等可交互区域
- [ ] 元素识别准确率≥95%
- [ ] 能够为每个识别区域生成标准坐标（X、Y、宽、高）
- [ ] 坐标生成耗时≤100ms
- [ ] 坐标体系统一使用屏幕绝对坐标
- [ ] 忽略无效背景区域，只保留可交互有效元素
- [ ] 支持多显示器场景（主显示器(0,0)，副显示器坐标基于主显示器偏移）
- [ ] 支持高DPI屏幕适配（自动处理Windows DPI缩放）

## AGENT-COMM - 通信模块
- [ ] 通信模块能够标准化压缩打包数据
- [ ] 通信模块能够过滤无效数据、空坐标、损坏图像
- [ ] 通信模块能够转发数据至决策智能体（OpenAI API）
- [ ] 通信模块能够校验AI返回指令格式，错误格式直接拦截
- [ ] 通信异常时能够触发重试机制，重试3次，间隔1s，连续失败3次终止任务

## AGENT-DECISION - 决策AI智能体
- [ ] 决策AI仅输出纯指令内容（无解释、无科普、无多余文字）
- [ ] 决策AI一轮对话只输出单步操作
- [ ] 决策AI生成的所有操作匹配画面真实元素
- [ ] 决策AI严格使用坐标定位/元素名称定位两种标准格式
- [ ] 决策AI不会生成高危指令（修改注册表、修改环境变量、格式化磁盘、删除系统文件、篡改系统权限、启动/终止系统进程、写入/读取敏感文件等）

## AGENT-EXEC - 指令解析子模块
- [ ] 指令解析子模块能够识别指令类型（click/wait/end）
- [ ] 指令解析子模块能够解析坐标参数、目标元素、等待时长
- [ ] AI返回空指令或多指令时，终止任务并提示

## AGENT-EXEC - 安全校验子模块
- [ ] 安全校验子模块内置安全黑名单，能够拦截高危违规操作指令
- [ ] 安全校验子模块对未知指令直接忽略
- [ ] 坐标越界、元素不存在时，安全校验子模块放弃操作并上报异常
- [ ] 所有操作基于实时屏幕画面判定，杜绝无依据盲目操作

## AGENT-EXEC - 操作执行子模块
- [ ] 操作执行子模块能够精准调用本地键鼠接口完成click操作，坐标误差≤±5像素
- [ ] 操作执行子模块能够正确执行wait操作
- [ ] end指令触发后，操作执行子模块立即停止所有循环与后台监听
- [ ] 操作完成后，操作执行子模块反馈执行结果，触发下一轮画面刷新循环
- [ ] 键鼠操作被系统拦截时，终止任务并提示
- [ ] 支持多显示器和高DPI屏幕，操作精准

## 闭环循环流程
- [ ] 完整工作流程能够循环运行：屏幕捕获→元素识别→数据推送→AI决策→指令解析→安全校验→指令执行→画面刷新
- [ ] 系统实现单步指令执行模式，复杂任务分步执行
- [ ] 系统全程保持闭环循环逻辑，无额外冗余功能
- [ ] 支持用户手动中断流程

## 异常处理
- [ ] 系统具备截图失败异常处理
- [ ] 系统具备网络异常处理
- [ ] 系统具备AI返回格式错误处理
- [ ] 系统具备执行超时处理
- [ ] 系统具备元素识别失败异常处理（如画面无任何可交互元素）
- [ ] 系统具备AI返回空指令/多指令异常处理
- [ ] 系统具备键鼠操作被系统拦截异常处理
- [ ] 系统具备用户手动中断流程异常处理
- [ ] 各类异常场景能够被正确捕获和处理，不会导致系统崩溃

## 环境适配
- [ ] 代码适配主流 Windows 桌面环境（Windows 10/11）
- [ ] 在Windows 10环境运行正常
- [ ] 在Windows 11环境运行正常
