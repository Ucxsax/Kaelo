## 项目简介
一款轻量化桌面视觉自动化闭环项目，本地程序实时捕获屏幕、构建全局坐标体系，将画面图像+元素坐标同步发送给AI智能体；AI根据画面内容与用户需求生成标准化操作指令，本地程序解析并自动执行键鼠操作，实现**视觉识别—坐标分发—AI决策—本地执行**全自动链路。

## 核心能力
1. 屏幕实时识别，自动生成全局统一坐标坐标系，标记界面可交互元素。
2. 打包区域截图+元素坐标数据，标准化传输至AI智能体。
3. AI智能体理解用户需求、结合视觉画面，输出合规可解析操作指令。
4. 本地程序解析指令，自动执行鼠标点击、等待、终止任务等桌面行为。
5. 循环运行模式，持续跟随界面变化迭代操作，直至任务完成。

## 技术栈
- 视觉捕获：桌面截屏、界面元素检测
- 自动化引擎：模拟鼠标操作
- 通信方式：标准化结构化数据传输
- 运行环境：Windows

## 🚀 快速开始

### 前置要求
- Windows 10 或 Windows 11
- Python 3.8+
- **二选一**：
  - OpenAI API Key (或兼容 API)
  - 或 Ollama（本地运行免费模型）

### 安装方法

#### 1. 获取项目
```bash
cd e:\Kaelo
```

#### 2. （可选）创建虚拟环境
```bash
python -m venv venv
venv\Scripts\activate
```

#### 3. 安装依赖
```bash
# 方式一：以可编辑模式安装（推荐，可直接用 kaelo 命令）
pip install -e .

# 方式二：普通安装
pip install .

# 方式三：如果安装失败，也可以直接安装依赖
pip install -r requirements.txt
```

### 配置方法

#### 1. 创建配置文件
```bash
copy .env.example .env
```
注：OpenAI API调用疑似有BUG 建议使用Ollama
#### 2. 配置 AI 服务（二选一）

**选项一：使用 OpenAI API**
编辑 `.env` 文件：
```env
AI_SERVICE=openai
OPENAI_API_KEY=你的_api_key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o
```

**选项二：使用 Ollama（免费本地）**
1. 首先下载安装 Ollama：https://ollama.com/
2. 下载一个视觉模型：
   ```bash
   ollama pull llama3.2
   # 或其他支持视觉的模型：qwen2.5, minicpm-v 等
   ```
3. 编辑 `.env` 文件：
```env
AI_SERVICE=ollama
OLLAMA_BASE_URL=http://localhost:11434/v1
OLLAMA_MODEL=llama3.2
```

### 使用方法

#### 基本用法
```bash
# 如果已安装，可以直接使用 kaelo 命令
kaelo "你的自动化需求"

# 如果没有安装，也可以直接运行
python main.py "你的自动化需求"
```

#### 实用示例
```bash
# 打开 Windows 计算器
kaelo "打开计算器"

# 打开记事本
kaelo "打开记事本并输入 Hello World"

# 点击某个按钮
kaelo "点击开始按钮"
```

#### 其他命令
```bash
# 查看帮助
kaelo --help

# 查看版本
kaelo --version
```

## 运行流程
屏幕捕获 → 元素识别 & 坐标构建 → 图像+坐标数据推送AI → AI生成操作指令 → 本地安全校验 → 指令解析执行 → 循环刷新画面 / 任务结束

## 安全约束
- 拒绝高危系统操作、文件破坏、系统配置篡改等危险指令。
- 所有操作基于实时屏幕画面判定，杜绝无依据盲目操作。
- 单步指令执行模式，复杂任务分步执行，降低错误风险。

## 开发 & AI 编码行为规范
### 通用要求
1. 开发前完整阅读本仓库 `README.md`、各类 Agent 规范文档，严格遵循文档约束开发。
2. 禁止私自新增功能、修改交互格式、扩充操作类型、篡改项目核心流程。
3. 模块化编写代码，功能解耦：屏幕捕获、坐标计算、AI通信、指令解析、操作执行独立拆分。

### 代码规范
- 逻辑简洁、注释精简、可直接运行，适配主流 Windows 桌面环境。
- 完善异常捕获：截图失败、网络异常、AI返回格式错误、执行超时等场景。
- 严格对接Agent输出格式，程序仅解析规范指令，非法内容直接拦截丢弃。

### 交互规范
- 本地程序仅做指令执行层，决策逻辑完全交由对应AI智能体负责。
- 严格单向数据推送：本地上传画面与坐标，AI下发操作指令。
- 全程保持闭环循环逻辑，无额外冗余功能。

### 使用的AI模型
 - Doubao网页版超能模式（Beta）提供提示词
 - Trae IDE提供Vibe Coding环境
 - Doubao-Seed-2.0-Code提供编码
